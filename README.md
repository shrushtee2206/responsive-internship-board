# Responsive Internship Board

## EdVyro Full Stack Development - Task 2

A responsive and accessible internship listing interface built using:

- HTML5
- CSS3
- JavaScript
- DOM APIs
- JSON data

## Features

- Responsive design
- Internship cards
- Search functionality
- Domain filtering
- Work mode filtering
- Empty state
- Loading state
- Error state
- Retry button
- Internship details dialog
- Application form
- Keyboard-friendly controls
- Accessible form labels
- Mobile, tablet and desktop layouts

## Internship Data

The project uses the internship records supplied for the EdVyro task.

## Responsive Testing

Tested at:

- 360px mobile
- 768px tablet
- Desktop width
